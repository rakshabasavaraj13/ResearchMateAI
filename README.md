# 📚 ResearchMate AI

An autonomous AI research agent that transforms a research topic into a structured academic research report.

## ✨ Features

- 🔎 Automatic academic literature search
- 🧠 AI-powered paper analysis
- 📚 Literature survey generation
- 📊 Comparative analysis
- 🔍 Research gap identification
- 🚀 Future research directions
- 📝 Academic-format report generation
- 📄 PDF download
- 📝 DOCX download
- 🌐 Streamlit web interface

## 🔄 Workflow

Research Topic → Research Planning → Academic Literature Search → Paper Analysis → Literature Comparison → Research Gap Identification → Literature Survey → Academic Report → PDF / DOCX

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini
- OpenAlex
- LangChain
- ReportLab
- python-docx

## 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 🔐 API Keys

Configure API keys through Streamlit Secrets or environment variables.

- GOOGLE_API_KEY
- TAVILY_API_KEY (optional)

## 👩‍💻 Project

ResearchMate AI is a general-purpose academic research assistant. Enter any research topic and receive an automatically generated research report.
